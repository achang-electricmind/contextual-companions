# Changelog

## Initial proposal — 2026-11-01

This is the first presentation of Contextual Companions: reusable domain guidance that supplies the surrounding knowledge people need to participate effectively in their current activity.

The proposal includes the CCS standard, Git Companion, optional context adapter resources, three host packages, authoring tools and an evaluation approach. See [proposal contents and package identifiers](RELEASE-NOTES.md) and [validation status](docs/VALIDATION.md).

This log records published changes from this proposal onward.
